# Privacidad

RecetArIA no recibe chats originales. El investigador elige el material y el modelo. Un LLM remoto recibe el texto que se le proporcione; el aislamiento respecto del proyecto central no convierte ese procesamiento en local. Para evitar transmitirlo a un proveedor, usar un ejecutor local configurado por el investigador.

El registro de evidencia permanece separado en el equipo del investigador. No forma parte del JSON de envío. El draft permite únicamente campos declarados; texto libre y código siguen requiriendo revisión de datos personales y secretos. No hay detector automático que garantice anonimización.

La utilidad no usa red, no lee el historial, no busca credenciales y no envía archivos. SUBMIT autoriza únicamente el artefacto mostrado. El consentimiento se registra tras revisión; un booleano generado por un LLM no acredita identidad. El receptor futuro deberá autenticar al contribuidor y validar de nuevo. No guardar archivos personales dentro del repositorio. El borrado local y cualquier futura política de retención central deben explicarse antes de activar recepción.
