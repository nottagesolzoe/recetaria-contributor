Se inspeccionó «Receta 2 | Cómo saber si tu base está lista para empezar a analizar» en el Drive de Sol. Su estructura se usó para los encabezados del borrador. No se copió su contenido como receta de ejemplo ni se modificó el documento fuente. La especificación recién aportada por Sol es RECETARIA_SPEC.md y gobierna la elegibilidad y el estilo. La línea de mala práctica es opcional.

La estructura preserva tres momentos separados: decisiones con IA, implementación y comprobación. En recetas sin código se adapta el rótulo, no se exige programación. Ni el tema de la referencia ni sus controles se imponen a otros investigadores.
