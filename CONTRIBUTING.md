# Contribuir

Usá el paquete con tu propio material autorizado. Revisá candidatos, corregí el draft y elegí SUBMIT solo para la versión completa que quieras aportar. Tu nombre o seudónimo e identificador acordado deben conservarse. La utilidad prepara un archivo local; esperá el canal controlado de recepción. No uses issues, PRs ni commits para recetas con datos privados.

Sol realiza la revisión editorial central. DRAFT puede recibir CASI, REHACER o APROBADA únicamente allí. Contributor no modifica recetas canónicas. Las mejoras al software y los aportes de recetas son procesos distintos. No adjuntes conversaciones a informes de errores; prepará un ejemplo sintético.
